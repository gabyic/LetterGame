# Letter Quest 游戏设计文档

## 1. 目标用户与学习目标

- 用户：5~8 岁、刚开始英语课的小朋友（一男一女），Roblox 玩家
- 目标：
  1. 认读 26 个字母大小写，能区分易混字母
  2. 会按笔顺书写大小写
  3. 听到字母名能辨认；知道英式 / 美式读法差异（Z、R 等）
  4. 建立字母 → 首音 → 单词的自然拼读联系

## 2. 为什么用 Roblox 的语言

孩子已经在 Roblox 里熟悉这些概念，直接复用降低学习成本：

| Roblox 概念 | 游戏内对应 |
|---|---|
| Obby（跑酷闯关）| 每个字母 = 一关，7 个 checkpoint |
| Checkpoint | 任务进度条，做完一个亮一格 |
| Robux | 🪙 金币（常用）+ 💎 宝石（稀有）|
| Avatar 商店 | 帽子 / 宠物 / 衣服装扮方块小人 |
| Badge | 🏆 徽章墙 |
| Boss / 宝箱 | 岛屿 Boss 综合测验，通过开宝箱 |
| Daily Reward | 每日任务 + 连续打卡 |
| Leaderboard | 兄妹排行榜 |

## 3. 核心循环（Core Loop）

```
选关 → 7 个小任务（每题即时 +🪙 +✨）→ 结算（⭐ 星级 + 奖励）
     ↘ 商店花钱装扮 ↗          ↘ 徽章弹出 ↗
```

- **即时反馈**：每答对一题金币飞向头顶余额 + 音效；答错抖动 + 提示
- **短周期**：一关 2~3 分钟，适合注意力时长
- **中周期**：一个岛（5 关 + Boss）约 15 分钟，一次学习刚好
- **长周期**：5 个岛 + 等级 + 徽章 + 收集商店物品

## 4. 难度曲线

- 岛屿顺序即字母顺序，前一关通过才解锁下一关（obby 逻辑）
- 认读题的干扰项按字母表随机 + 易混字母优先（b/d/p/q，m/n/w，u/v）
- 描红判分：
  - 覆盖率：引导线上 ≥60% 的采样点被用户笔迹覆盖（Boss 关 70%）
  - 精确率：用户笔迹 ≥55% 落在引导线附近
  - 失败 3 次可跳过（不扣星以外的惩罚，避免挫败）
- Boss 关：本岛字母混合 8 题 + 1 个随机描红，无"Meet"提示

## 5. 奖励经济

| 行为 | 🪙 | 💎 | ✨XP |
|---|---|---|---|
| 答对一题 | 10 | | 5 |
| 描红成功 | 15 | | 5 |
| 首次通关 | 30 + 10×星 | 3 星 +1 | 30 + 5×星 |
| 重玩通关 | 10 + 5×星 | | 同上 |
| Boss | 100 + 30×星 | 3 + 星 | 80 |
| 每日任务 | 50~60 | | 20 |
| 徽章 | | 1 | |
| Letter Rush | 3 / 分 | | 2 / 分 |

商店定价：普通装扮 40~180 🪙（约 1~3 关），稀有 4~12 💎（需要几次 3 星 / Boss），形成"再冲一次 3 星"的动力。

## 6. 双人设计

- 各自档案、各自头像，同设备切换
- 排行榜按 XP 排，展示 ⭐ 和 🏆 数，形成良性比拼
- 不设 PVP 惩罚；未来可加"合作 Boss"（两人轮流答题）

## 7. 家长视角

- ⚙️ 家长面板：答对 / 答错 / 描写次数、连续天数、进度
- 手动发放奖励金币（作为现实奖励的联动，例如完成作业 +50）
- 音效开关

## 8. 可扩展方向

1. **单词岛**：三字母 CVC 单词（cat, dog）拼写关
2. **句子跑酷**：把字母跑酷变成"听句子选图"
3. **真人录音**：用家长 / 老师的录音替换 TTS
4. **Roblox 版**：见 `ROBLOX.md`，把同一套题库搬进 Roblox Studio 做成真正的 3D obby
5. **云存档**：加一个简单后端（或 Firebase）跨设备同步
